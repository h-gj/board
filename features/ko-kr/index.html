기본 그래픽

먼저 물건을 그려보세요

스케치, 공식 흐름도, 인터페이스 프로토타입, 마인드 맵은 모두 동일한 도구 세트와 동일한 종이를 사용합니다. 파일 형식을 결정할 필요 없이 아이디어가 있는 레이어에 그림을 그립니다.

무한 캔버스

캔버스는 가장자리까지 채워지지 않습니다. 원하는 곳에 그림을 그리고, 10%까지 확대하면 전체 그림을 한눈에 볼 수 있습니다.

흐름도

모양을 선택하고 연결을 시작하면 됩니다. 스스로 길을 찾아보세요. 엉망인 레이아웃은 한 번의 클릭으로 다시 정렬할 수 있으므로 모든 라인을 수동으로 정렬할 필요가 없습니다.

와이어프레임 프로토타입

탐색 표시줄, 양식, 카드 및 팝업 창은 모두 미리 만들어진 구성 요소입니다. 이를 드래그하여 단일 화면 프로토타입을 만듭니다.

마인드맵

12개의 레이아웃, 8개의 색상 세트로 노드를 드래그하면 전체 트리가 자동으로 재정렬됩니다. 접힌 부분, 주석, 테두리 및 연결선이 모두 있습니다.

테이블과 수영 레인

책임의 행과 선은 스스로 정렬되어 있으며 선을 추가해도 전체 그림이 왜곡되지는 않습니다.

손으로 그린 스타일

초안의 어조는 의견을 불러일으킵니다. 배송 시에는 스위치가 일반 라인으로 교체됩니다.

이미지 처리

사진은 첨부파일이 아닌 자료입니다.

스크린샷을 게시한 후 편집해야 하는 경우가 많습니다. 불필요한 부분을 잘라내고, 민감한 부분을 덮고, 여러 장의 그림을 하나로 결합합니다. 모두 이미지 도구를 사용하여 앞뒤로 잘라낼 필요 없이 캔버스에 있습니다.

자르기 프레임을 드래그하여 구성을 정의하면 언제든지 원본 이미지를 복원할 수 있습니다.
슬라이스 긴 그림을 여러 부분으로 나누어 전시하고 따로 이야기해 보세요.
모자이크 및 컷아웃 이름과 금액을 가리거나 배경 일부를 지우세요.
퍼즐 여러 장의 사진이 레이아웃에 따라 하나로 합쳐지고, 여백이 자동으로 정렬됩니다.

대형 캔버스 성능

그림이 가득 차 있어도 막히면 안 됩니다.

캔버스는 시간이 지남에 따라 무거워지며, 이는 모든 화이트보드의 실제 문제입니다. 우리는 이를 실패할 테스트로 간주합니다. 변경이 있을 때마다 실제 브라우저에서 10,000개의 요소를 드래그하고 확대/축소합니다. 지표가 떨어지면 이를 공개할 수 없습니다.
