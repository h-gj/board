基礎圖形

先把東西畫出來

草圖、正式流程圖、介面原型和腦圖，用的是同一套工具和同一張紙。想法在哪一層，就在哪一層畫，不用先決定這是什麼類型的文件。

無限畫布

畫布不會畫滿。想到哪畫到哪，縮到 10% 也能一眼看全整張圖。

流程圖

選好形狀就開始連，連線自己找路徑。版面亂了一鍵重排，不用手動對齊每一根線。

線框原型

導覽列、表單、卡片、彈跳窗都是現成組件，拖出來就是一屏可講的原型。

心智圖

十二種佈局、八套配色，拖曳一個節點整棵樹自動重排。折疊、批註、邊界和關聯線都在。

表格與泳道

行列和職責帶自己保持對齊，加一行不會把整張圖擠歪。

手繪風格

草稿的語氣讓人願意提出意見。要交付時，一個開關換成規整線條。

導入與轉換

已經寫好的，不用重畫

文件裡的 Mermaid、倉庫裡的 PlantUML、draw.io 和 Visio 的存檔、別處導出的腦圖，拖進來就變成畫布元素。 

graph LR
  A[接單] --> B{庫存充足?}
  B -->|是| C[出庫]
  B -->|否| D[補貨]

這個「出庫」，真的可以拖走

右邊這些是元素，不是圖片——可以拖走一個節點、改一句文案、換一種配色，再接著往下畫。

文件與程式碼

原件就攤在畫布上

把 PDF、合約、報表或一段程式碼拖進來，它們不是要下載的附件，而是能在畫布上直接翻頁、直接讀取的一塊內容。

程式碼區塊

語法高亮跟著語言走。寫的是網頁程式碼，畫布上立刻能看到渲染出來的樣子。

// order.ts export const settle = (order: Order) => { if (!order.paid) return "待支付"; return ship(order); };

文件預覽

逐頁翻，也能一次鋪上對照。原始文件始終留在這塊元素裡，隨畫布一起分享。

圖片處理

圖片是素材，不是配件

截圖貼進來往往還要再修一刀。裁掉多餘的、遮住敏感的、把幾張拼成一張，都在畫布上完成，不用來回切圖片工具。

裁切 拖邊框定構圖，原圖隨時能還原。
切片 長圖一刀切成幾段，分開擺、分開講。
馬賽克與摳除 遮掉姓名和金額，或直接擦掉一塊背景。
拼圖 幾張圖按版面合成一張，邊距自動對齊。

本機智慧圖像

高清增強與智慧去背

兩項能力全部在你的裝置本機完成。圖片無需上傳，處理過程不離開裝置。

高清增強 放大並修復模糊與壓縮痕跡，讓照片和插圖更清楚。
智慧去背 自動辨識人像和物件，一鍵去除背景，邊緣細節也能保留。

大畫布性能

畫滿了也不該卡

畫布用久了會變重，這是所有白板的真問題。我們把它當成會失敗的測試來管：每次改動都在真實瀏覽器裡跑一萬個元素的拖曳和縮放，指標退了就不許發版。

— fps 10,000 元素 · 即時渲染

這塊就是一萬個元素：按住拖曳一拖 · 雙指捏合或 ⌘/Ctrl + 滾輪縮放

以下是最近一次通過的基準結果，不是宣傳口徑。
場景 實測 意義
一萬元素同屏拖曳 9.5 ms 幀耗時 p95。60fps 的預算是 16.7 ms，還剩一半餘裕。
拖曳中的掉幀 0.23 % 超出 60fps 預算的幀佔比，一千幀裡約兩幀。
縮放到 10% 5 ms 從滾輪輸入到畫面響應，p95。
二十張 4K 圖 ↓ 70 % 分級預覽相比全尺寸解碼省下的開銷，快取控制在 192 MiB 內。

測量條件：Chromium 150、Apple M1 Max，真實 Canvas2D 渲染路徑，10,000 個全部位於首屏的元素，幀間隔取自 performance.now() 壁鐘。基準腳本和歷史結果都在開源倉庫。
