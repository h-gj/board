## 部署
本仓库是构建产物（静态站点）。推送到 `main` 分支即由 GitHub Pages 发布。
自定义域名由根目录 `CNAME` 声明。
> `.gitattributes`（`* -text`）用于锁死字节保真，请勿删除——删掉会让 git 在检出时改写文件字节。
