无需登录，也不用先把文件搬到云端。打开画布，直接处理电脑里的图片、文档和图表。

无需登录

不注册，不选模板。打开就是一张可编辑的空白画布。

本地文件直接操作

图片、PDF 和图表直接导入，在画布上查看、编排和继续处理。

处理全程留在本机

文件无需上传，内容、处理过程和结果都留在自己的设备里。

基础图形

先把东西画出来

草图、正式流程图、界面原型和脑图，用的是同一套工具和同一张纸。想法在哪一层，就在哪一层画，不用先决定这是什么类型的文件。

无限画布

画布不会画满。想到哪画到哪，缩到 10% 也能一眼看全整张图。

流程图

选好形状就开始连，连线自己找路径。布局乱了一键重排，不用手动对齐每一根线。

线框原型

导航栏、表单、卡片、弹窗都是现成组件，拖出来就是一屏可讲的原型。

思维导图

十二种布局、八套配色，拖动一个节点整棵树自动重排。折叠、批注、边界和关联线都在。

表格与泳道

行列和职责带自己保持对齐，加一行不会把整张图挤歪。

手绘风格

草稿的语气让人愿意提意见。要交付时，一个开关换成规整线条。

导入与转换

已经写好的，不用重画

文档里的 Mermaid、仓库里的 PlantUML、draw.io 和 Visio 的存档、别处导出的脑图，拖进来就变成画布元素。 

graph LR

右边这些是元素，不是图片——可以拖走一个节点、改一句文案、换一种配色，再接着往下画。

文档与代码

原件就摊在画布上

把 PDF、合同、报表或一段代码拖进来，它们不是待下载的附件，而是能在画布上直接翻页、直接读的一块内容。

代码块

语法高亮跟着语言走。写的是网页代码，画布上立刻能看到渲染出来的样子。

// order.ts export const settle = (order: Order) => { if (!order.paid) return "待支付"; return ship(order); };

文档预览

逐页翻，也能一次铺开对照。原始文件始终留在这块元素里，随画布一起分享。

图片处理

图片是素材，不是附件

截图贴进来往往还要再修一刀。裁掉多余的、遮住敏感的、把几张拼成一张，都在画布上完成，不用来回切图片工具。

裁剪 拖边框定构图，原图随时能还原。
切片 长图一刀切成几段，分开摆、分开讲。
马赛克与抠除 遮掉姓名和金额，或直接擦掉一块背景。
拼图 几张图按版式合成一张，边距自动对齐。

本地智能图像

高清增强与智能抠图

高清增强、智能抠图全部本地化处理。图片无需上传，处理过程不出端。

高清增强 放大并修复模糊与压缩痕迹，让照片和插图更清楚。
智能抠图 自动识别人像和物体，一键去掉背景，边缘细节也保留。

大画布性能

画满了也不该卡

画布用久了会变重，这是所有白板的真问题。我们把它当成会失败的测试来管：每次改动都在真实浏览器里跑一万个元素的拖拽和缩放，指标退了就不许发版。

— fps 10,000 元素 · 实时渲染

这块就是一万个元素：按住拖一拖 · 双指捏合或 ⌘/Ctrl + 滚轮缩放

下面是最近一次通过的基准结果，不是宣传口径。
场景 实测 含义
一万元素同屏拖拽 9.5 ms 帧耗时 p95。60fps 的预算是 16.7 ms，还剩一半余量。
拖拽中的掉帧 0.23 % 超出 60fps 预算的帧占比，一千帧里约两帧。
缩放到 10% 5 ms 从滚轮输入到画面响应，p95。
二十张 4K 图 ↓ 70 % 分级预览相比全尺寸解码省下的开销，缓存控制在 192 MiB 内。

测量条件：Chromium 150、Apple M1 Max，真实 Canvas2D 渲染路径，10,000 个全部位于首屏的元素，帧间隔取自 performance.now() 壁钟。基准脚本和历史结果都在开源仓库里。
