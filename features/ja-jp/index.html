画像、PDF、チャートを直接インポートして表示、整理し、キャンバス上で作業を続行します。

プロセス全体がローカル マシン上に残ります

ファイルをアップロードする必要はなく、コンテンツ、処理、結果は自分のデバイスに残ります。

基本的なグラフィックス

最初に物事を描く

スケッチ、正式なフローチャート、インターフェイスのプロトタイプ、マインド マップはすべて、同じツール セットと同じ用紙を使用します。ファイルの種類を決めることなく、アイデアが浮かんだレイヤーに描画します。

無限のキャンバス

キャンバスは縁まで埋まりません。好きな場所に描画すると、10% に拡大して全体を一目で確認できます。

フローチャート

形状を選択して接続を開始するだけです。自分で道を見つけてください。乱れたレイアウトはワンクリックで再配置でき、手動で各行を揃える必要はありません。

ワイヤーフレームプロトタイプ

ナビゲーション バー、フォーム、カード、ポップアップ ウィンドウはすべて既製のコンポーネントです。それらをドラッグして 1 画面のプロトタイプを作成します。

マインドマップ

12 のレイアウト、8 つのカラー セットでノードをドラッグすると、ツリー全体が自動的に再配置されます。折り目、注釈、境界線、関連線がすべて存在します。

テーブルとスイムレーン

責任の行と線は常に整列しており、線を追加しても全体像が歪むことはありません。

手描きスタイル

草案の論調についてはコメントを求めている。スイッチは通常の回線に置き換えられて納品されます。

インポートと変換

すでに書かれているので書き直す必要はありません

ドキュメント内の Mermaid、ウェアハウス内の PlantUML、draw.io と Visio のアーカイブ、および他の場所にエクスポートされたマインド マップをドラッグしてキャンバス要素に変えることができます。 

graph LR
  A[注文を受ける] --> B{在庫は十分ですか？}
  B -->|はい| C[倉庫から出た]
  B -->|いいえ| D[再入荷]

この「デク」は本当に牽引できるんです

これらは右側にあります画像ではなく要素——ノードをドラッグして遠ざけ、コピーライティングの文章を変更し、色を変更して、描画を続けることができます。

ドキュメントとコード

キャンバス上にオリジナルが広がる

PDF、契約書、レポート、またはコードの一部をドラッグします。これらはダウンロードする添付ファイルではなく、キャンバス上で直接ページングして読み取ることができるコンテンツです。

コードブロック

構文の強調表示は言語に従います。書かれているのはWebコードであり、レンダリングはキャンバス上ですぐに見ることができます。

// order.ts export const settle = (order: Order) => { if (!order.paid) return 「支払われるべき」; return ship(order); };

ドキュメントのプレビュー

ページをめくって一度に比較できます。元のファイルは常にこの要素内に残り、キャンバスと共有されます。

画像処理

写真は素材であり、添付ファイルではありません

多くの場合、スクリーンショットは投稿後に編集する必要があります。画像ツールを使用して前後に切り取ることなく、キャンバス上で余分な部分を切り取り、デリケートな部分をカバーし、複数の写真を 1 つに結合します。

作物 フレームをドラッグして構図を定義すると、いつでも元の画像に戻すことができます。
スライス 長い写真をいくつかのセクションに切り分けて表示し、個別に説明します。
モザイクと切り抜き 名前と金額をブロックするか、単に背景の一部を消去します。
パズル 複数の写真をレイアウトに合わせて1枚に結合し、余白も自動で調整されます。

ローカルスマートイメージ

HD エンハンスメントとインテリジェントなカットアウト

どちらの機能もデバイス上でローカルに完了します。画像をアップロードする必要がなく、処理プロセスがスムーズです。

HD強化 ズームインしてぼやけや圧縮アーティファクトを修正し、写真やイラストをより鮮明にします。
スマートなカットアウト ポートレートやオブジェクトを自動的に認識し、ワンクリックで背景を削除し、エッジの詳細を保持します。

大きなキャンバスのパフォーマンス

絵がいっぱいになっても動かないはずです。

キャンバスは時間の経過とともに重くなりますが、これはすべてのホワイトボードに共通する問題です。これを失敗するテストとして扱います。変更を加えるたびに、実際のブラウザで 10,000 個の要素のドラッグとズームを実行します。インジケーターが下がった場合、それをリリースすることはできません。
